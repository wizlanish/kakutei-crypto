# /crypto-tax — 暗号資産の雑所得を計算する

あなたの役割は**読むこと**であり、**計算すること**ではない。
所得金額・売却原価・平均単価を自分で計算してはならない。数字はすべて `kakutei calc` の出力から引用する。

## 前提

- `kakutei` コマンドが必要。無ければ README の「インストール」に従ってもらう（リポジトリを clone して `pip install .`、または `pipx install git+<リポジトリ URL>`）。
- 作業フォルダはユーザーに決めてもらう。取引履歴は個人情報なので、git リポジトリの中に置かないよう伝える。

## 手順

### 1. ファイルを集める
指定フォルダの CSV / PDF を列挙し、どの交換業者の何のファイルかを表にして見せる。足りないものがあれば伝える:
- 計算する年の全期間が揃っているか（OKJ は CSV 作成時の期間指定に制限があるため、分割ダウンロードが多い）
- 送付先・送付元の交換業者の履歴もあるか（無いと取得価額が欠ける）
- 前年以前から保有している場合は、前年末の数量・簿価（前年分の計算書の H・I 欄）

### 2. 既知形式を取り込む
```
kakutei import <CSV...> -o ledger.csv
```
対応形式: OKJ 注文履歴・入出金口座履歴、Coincheck 様式1。終了コード 2 は未対応ファイルあり。

### 3. 未対応ファイル・PDF を台帳にする（あなたの出番）
未対応の CSV や PDF（例: bitFlyer の月次「取引報告書 兼 取引残高報告書」）は、自分で読んで **別ファイル** `manual/<元ファイル名>.ledger.csv` に統一台帳の行を書く。列は次のとおり:

`id,timestamp,exchange,kind,in_asset,in_qty,out_asset,out_qty,jpy_value,fee_asset,fee_qty,source,note`

- `kind`: buy / sell / swap / reward / fork / transfer_in / transfer_out / opening
- 数量は正の数。`timestamp` は `2026-08-18T12:42:00+09:00` の形式（JST）。
- `jpy_value`: buy は支払額、sell は受取額、swap・reward は取引時点の時価、opening は前年末の簿価。
- `source` に必ず出典を書く（`ファイル名 p.2` や `ファイル名#行番号`）。
- 推測で埋めた値には、`note` に「推定」と理由を書く。
- **作った行は表にしてユーザーに見せ、確認を取る。**

例（bitFlyer 月次報告書の入出金明細）:
```
受取 POL 362.46875 → kind=transfer_in, in_asset=POL, in_qty=362.46875
手数料 POL -26 / 送付 POL -336.46875 → kind=transfer_out, out_asset=POL, out_qty=336.46875, fee_asset=POL, fee_qty=26
```

### 4. チェックを通す
```
kakutei check ledger.csv manual/*.ledger.csv
```
- **エラー「jpy_value が必要」**: 時価をユーザーに尋ねるか、交換業者が公表している価格を調べる。調べた場合は出典を note に書く。**数値をでっち上げない。**
- **エラー「保有数量がマイナス」**: 取込み漏れ。どのファイルが足りないかをユーザーに伝える。前年からの保有なら opening 行を作る。
- **注意「対応する送付が台帳にありません」**: 送付元の履歴を追加するか、実は報酬・購入なら kind を直す（ユーザーに確認する）。
- **注意「要確認」**: 入出金内容を見て、報酬なら kind=reward と jpy_value を設定する（ユーザーに確認する）。

### 5. 計算する
```
kakutei calc ledger.csv manual/*.ledger.csv --method total --xlsx out/計算書.xlsx
```
- 評価方法の届出をしていなければ総平均法（`total`）。移動平均法の届出がある場合だけ `--method moving`。
- 結果は端末の出力をそのまま引用して説明する。xlsx の場所も伝える。

### 6. 最後に必ず伝えること
- 対象外の取引（証拠金・CFD・DeFi・NFT・海外交換業者）があれば、計算に含まれていないこと。
- 給与所得者で雑所得等の合計が 20 万円以下なら所得税の確定申告が不要な場合があるが、住民税の申告は別途必要になりうること。
- これは計算の補助であり、最終的な申告内容は本人（必要なら税理士・税務署）が確認すること。
